**根因（Lead 裁决 2026-10-18）**：主人的约定是「**全部技能 4 级** + 补最低要求」，

- `3413 Power Grid Management` 没有任何模块"要求"它 → 不在默认档 → PG 输出不放大（54）；
- `3449 Navigation` 被间接要求 → 在默认档 → 速度 ×1.2（1271.61）。

文档里的 64.8 / 1059.68 来自手工挑选的技能集，**两个方向都被这个偏差影响**：
一处多算了 PGM、一处少算了 Navigation。所以：

- **这不是文档笔误，是实现的语义偏差** → 修实现（**T-12**），修完整体重标快照；
- 修复前 `check_snapshot.py` 进入 `skip-until-rebaseline`，这两行**不作为缺陷、也不作为验收依据**。

## 7. 我对口径的理解自检（请 Lead 核对我理解是否正确）

1. **技能档默认 = 全 4 + 补最低**，`skill_tier_name = all4+min_required`，本样本 19 个技能（17×4 + 2×5）。
2. **单位只在 `project/units.py` 入口换算**；业务代码只拿秒/米；`alignTime(-1)` 已是秒，
   `warpSpeedMultiplier(600)` 的值即 AU/s（Hecate = 4.5）。
3. **混合 EHP 按层复算**，`Σ_layer HP / Σ(w×r)`（r 是共振率，所以是乘），既不等于算术平均也不等于调和平均。
4. **火力聚合不要自己加**：`ship -11` 就等于 Σ item `-21`，`-12`/`-13` 同理。
5. **档位违规 vs 硬违规**：`resource` + `skill` → `tier_violations`；其余（`charge_size` /
   `charge_group` / `slots` / `max_group` / rig 尺寸 …）→ `hard_violations`。
6. **provenance 与可信度是两个正交维度**（Lead 裁决 2026-10-18）：provenance 只表达
   「是否依赖假设」，权威在 `evefit/project/provenance.py`；「未建模」用 `confidence=E` 表达。
7. **模式是独立 type（group 1306）**，通过 `fit.ship.mode = <type_id>` 生效；Heacate 三模式
   对 EHP/DPS/对齐的影响分别为 +38% / +33% / −67%（方向已由我的 fixture 复现）。
